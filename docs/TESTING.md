# Тестирование HYPERREAL SHADERS v1.0

## 1. Что было доступно в среде разработки

| Инструмент | Наличие |
|---|---|
| `glslangValidator` 11.7.0 (Glslang) | есть, использован |
| Python 3 / Node.js / zip | есть |
| GPU + OpenGL 3.3 контекст | **нет** (нет `libGL`/EGL, нет root) |
| Java / Minecraft 1.20.4 / Iris | **нет** |
| `moderngl` (попытка оффскрин-рендера) | установлен, но контекст создать невозможно |

Поэтому **запуск игры в этой среде был невозможен**. Ниже — что реально проверено, а что осталось
на ручную проверку в игре. Никакие результаты не выдуманы: всё, что написано как «пройдено», получено
запуском инструментов из этого репозитория.

## 2. Автоматическая проверка (пройдена)

```
$ python3 tools/compile_shaders.py
using .../glslangValidator.linux (Glslang Version: 10:11.7.0)

40/40 programs compiled
20 vertex/fragment pairs linked
all programs compiled and linked successfully
```

Что делает `tools/compile_shaders.py`:

1. Раскрывает `#include` рекурсивно (ведущий `/` — от корня `shaders/`, иначе относительно файла);
   ловит циклы включений и выход за пределы каталога.
2. Компилирует каждый `*.vsh` и `*.fsh` независимо через `glslangValidator` с профилем
   `#version 330 compatibility`.
3. Линкует каждую пару вершинный + фрагментный (`glslangValidator -l`), то есть проверяет совпадение
   `varying`/in-out между стадиями.

```
$ python3 tools/check_pack.py
pack structure OK (40 programs, 82 options, 6 presets, 0 warning(s))
```

Что делает `tools/check_pack.py` (проверки, которых не видит компилятор):

* `#version` — первая строка программы, в `lib/*.glsl` его нет вовсе;
* `DRAWBUFFERS` ↔ количество и порядок `layout(location = N) out`;
* ни один проход не читает буфер, в который пишет (framebuffer feedback = чёрный экран);
* `gbuffers_*` и `shadow.*` не читают `colortex0..3` (Iris их не отдаёт миру);
* у каждого используемого буфера объявлен формат, формат — из списка допустимых Iris, а директива
  формата лежит внутри блочного комментария (иначе GLSL не скомпилируется);
* все опции, на которые ссылается `shaders.properties`, объявлены в `lib/settings.glsl`, и наоборот
  (неиспользуемая опция — warning);
* `screen`/`screen.<NAME>`/`sliders`/`profile.<NAME>` согласованы между собой;
* для каждого экрана, опции и пресета есть ключ в `lang/ru_ru.lang` и `lang/en_us.lang`;
* `clouds=off`, `blend.gbuffers_water=off`, `blend.gbuffers_hand_water=off` присутствуют;
* `block.properties`: синтаксис, валидность id блоков 1.20.4, соответствие константам `lib/materials.glsl`.

Итог: **0 проблем, 0 предупреждений**.

## 3. Ошибки, найденные и исправленные в процессе

| Симптом | Причина | Исправление |
|---|---|---|
| `getShadowVisibilityFast`: no matching overloaded function | `composite.fsh`, `composite1.fsh`, `composite3.fsh`, `final.fsh` использовали функцию из `lib/shadows.glsl`, не включив его | добавлен `#include "/lib/shadows.glsl"` в четыре прохода |
| `functions with mutually recursive dependency` | `skyFallback()` в `lib/composite_common.glsl` вызывал `renderSkyCheap()` из `sky.glsl`, который сам зависит от composite-хелперов | функция удалена, фолбэк неба реализован на месте вызова (после включения `sky.glsl` + `clouds.glsl`) |
| `RGBA16F: undeclared identifier` | директивы `const int colortexNFormat` были раскомментированы | формат вынесен в `lib/buffers.glsl` **внутрь** блочного комментария: GLSL его не видит, а парсер Iris/OptiFine (построчный) — видит |
| `block.properties: continuation` | длинные списки блоков были свёрнуты через `\` | каждый id — на одной строке (переносимо для обоих загрузчиков) |
| `mc_Entity` / `at_tangent` подчёркивались как неизвестные | проверялось вручную по `ProgramCreator.java`/`SodiumPrograms.java` Iris | подтверждено: локации 11/12/13/14, компилятор принимает |
| Ложное «missing #endif» рядом с `no matching overloaded` | следствие нерешённой зависимости функции, а не скобок | включения переставлены в правильном порядке |

## 4. Что проверено формально, но не в игре

* Синтаксис и типы всех выражений — компилятором (это ловит опечатки, неверные сигнатуры, отсутствие
  `return`, несовпадение типов, обращения к необъявленным uniform'ам).
* Согласованность стадий — линковкой.
* Согласованность буферов и опций — `check_pack.py`.

## 5. Что НЕ проверено (нужен реальный запуск)

Честный список того, что статический анализ подтвердить не может:

1. **Визуальный результат** каждого эффекта (цвет, интенсивность, отсутствие артефактов).
2. **Производительность** (FPS) на конкретных GPU.
3. **Поведение драйверов** NVIDIA/AMD/Intel на шейдерах с `gl_TextureMatrix`, `ftransform()`,
   большими циклами с `break`.
4. **OptiFine 1.20.4** — совместимость по директивам заявлена, но не проверена.
5. **Совместимость с PBR-ресурспаками** на реальных текстурах (логика детекта `_n`/`_s` написана по
   спецификации labPBR, но не прогнана на наборе текстур).
6. **Пограничные ситуации:** смена измерения, телепорт, spectator, вода на границе чанков, стекло
   с кастомными моделями.

## 6. Как повторить проверки

```bash
# зависимость: glslangValidator (бинарник или npm glslang-validator-prebuilt)
cd /path/to/repository
python3 tools/compile_shaders.py          # компиляция + линковка
python3 tools/check_pack.py               # структура пака
python3 tools/build_zip.py                # сборка dist/HYPERREAL-SHADERS-v1.0.zip
```

Валидатор ищет `glslangValidator` в `PATH` и в известных местах; альтернативный путь задаётся
флагом `--glslang`.

## 7. Ручной чек-лист в игре (5–10 минут)

1. Загрузите мир с водой, лесом и горами; поставьте HIGH.
2. Закат: цвет неба, диск солнца, длинные тени, god rays в лес.
3. Ночь: звёзды, фаза луны, сияние, лунные тени.
4. Дождь и гроза: мокрые поверхности, вспышки, тени от облаков.
5. Под водой: поглощение, каустики на дне, подводные лучи.
6. Пещера с факелом: динамический свет в руке, SSAO, отсутствие акне на стенах.
7. Переключите пресеты LOW → EXTREME → HIGH: экран не должен чернеть или «залипать».
8. `DEBUG_VIEW` = 1..6: каждый вид показывает свой буфер.
9. Пройдитесь по стеклянной стене: прозрачность и отражения без поломки ванильных прозрачных блоков.
10. Смена измерения (Nether/End) и обратно: без чёрного экрана и без остатков прошлого кадра.
