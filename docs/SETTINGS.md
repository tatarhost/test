# Настройки HYPERREAL SHADERS v1.0

Все 82 опции объявлены один раз — в `shaders/lib/settings.glsl`; раскладка по экранам — в
`shaders/shaders.properties`; переводы — в `shaders/lang/ru_ru.lang` и `en_us.lang`.
Ниже полный справочник: имя, значения, умолчание и цена в кадре.

**Цена:** ⚪ почти бесплатно · 🔵 ~0.2–0.5 мс · 🟠 1–2 мс · 🔴 2–5 мс · ⚫ дороже 5 мс
(на RTX 3060, 1080p, вне пещер; в лесу/под водой дороже).

## Как менять файлы напрямую

* Быстро выключить эффект без GUI: удалите `#define` или закомментируйте строку в
  `shaders/lib/settings.glsl`.
* Слайдер задаётся строкой `#define NAME value // [a b c]` — значения в скобках должны включать
  текущее, иначе Iris не покажет опцию.
* Булевы опции: `#define NAME` (включено) или отсутствие define (выключено). Комментарий-описание
  пишется в `lang/*.lang`, а не в `settings.glsl`.
